Design decision for the BLE Companion Control feature (see .scratch/ble-companion-control/issues/11-migration-cutover-sequencing.md): does a firmware release ship with UART already gone before the Companion App exists, or is there an interim state? What's the README/docs rewrite plan for the removed UART command set?

Resolved decision: same-release, paired cutover — one version bump removes `uart.c` and ships the Control Service, with the Companion App shipping alongside it. No interim state where a device has its control surface removed but no replacement (log output survives per the console-output-fate decision, but no commands, so a gap would strand users). README rewrite: full rewrite in the same PR — the "Serial Menu Commands" section (`README.md`, ~lines 141-200+) is replaced with a Companion App usage guide (install/pair/screens) in that same PR, so the docs never describe a command surface that no longer exists.
