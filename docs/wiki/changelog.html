Changelog

What's new in each release. See GitHub Releases for the full history.

1.0.1 — February 18, 2026

  • Fixed a stall that could leave a connection queue stuck.
  • Fixed a crash that could occur during device handshakes.

1.0.0 — February 1, 2026

  • New: per-device settings, so each connected Pokémon GO account keeps its own Autospin and Autocatch state.
  • New: caught, fled, and spin counters shown per device.
  • New: log levels, for more or less detail when diagnosing a problem.
  • Autospin now pauses automatically when the item bag is full, and resumes on its own once there's room.
  • Reconnecting to a previously paired account is now faster and more reliable.
  • Settings are restored automatically on every new connection.
