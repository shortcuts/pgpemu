Settings

The Settings section controls how the device presents itself over Bluetooth: whether it's discoverable, how many connections it accepts at once, and how much detail it logs.

SettingWhat it does
Advertising Turns Bluetooth advertising on or off. While on, the device is visible to Pokémon GO and the companion app when they scan. Turn it off once everything you need is already paired, so it stops showing up to new scans. Existing connections aren't affected by turning it off.
Max connections The largest number of simultaneous Bluetooth connections the device accepts, from 1 to 4. Lower it to reserve the device for fewer accounts; raise it back up to 4 to allow the full set. See Multiple connections.
Log level How much detail the device records internally: Debug, Info, or Verbose. Tap Cycle log level to step through the options. Verbose is the most useful setting when you're trying to reproduce a problem to report.

Saving changes

Changes take effect right away, but tap Save to device to write Advertising, Max connections, and Log level to the device's flash storage so they're still set the next time it powers on. Without saving, these reset to their last saved value after a restart.
