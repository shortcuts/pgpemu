What you need

  • A PGPemu device and a USB data cable. Some cables only charge, so try another one if your computer does not see the device.
  • A computer with Chrome or Edge. Other browsers, and phones, cannot flash the device.
  • For a first install: your secrets.csv file, to load into the app afterwards.

Install the latest firmware

Plug the device into your computer, then click the button. The browser asks you to pick the device. The install takes about a minute. Do not unplug the device while it runs.

Your browser cannot flash the device. Use Chrome or Edge on a computer. Open this page over HTTPS to flash the device.

If the button does nothing, the latest release may not be published yet. Download the firmware from GitHub Releases instead.

First install

  1. Click the button and pick the device.
  2. Tick Erase device when the page offers it.
  3. Wait for the install to finish. The device restarts and shows up in the app as PGPemu Setup.
  4. Follow Set up a device with no secrets to load your secrets file.

Warning: erasing the device removes its secrets and all its pairings. Pair it with Pokémon GO again afterwards.

Update

  1. Click the button and pick the device.
  2. Leave Erase device unticked.
  3. Wait for the install to finish.

Your secrets and pairings stay. Pokémon GO reconnects by itself once the device restarts.
