Diagnostics and danger zone

Status

The Status card at the top of the dashboard is a read-only snapshot of the device. While you are connected, it and the device profiles refresh every few seconds. Changes from another phone show up without any action from you.

LED

Whether the device's indicator light is currently on.

Advertising

Whether the device is currently discoverable to new Bluetooth connections.

Radio

Whether the device is sending out its Bluetooth signal right now. It reads Idle when Advertising is off or when the max number of connections is already reached. Otherwise it reads Active. Newer firmware only.

Connections

How many devices are connected right now, out of the max set in Settings.

Battery

The charge left in the device's battery, as a percentage. This row only appears when your device has a battery reader fitted and runs newer firmware. Readings can be off by a few percent.

Log level

The device's current logging detail: Debug, Info, or Verbose.

About the device

On the About tab, the About device card shows details the app reads once when it connects: the firmware version, how many connection slots the device has, how long it has been running, why it last restarted (for example power on, a restart from the app, or a crash), and how much free memory it has. If the card says the device runs old firmware, update the device to see these details.

Crash report

If the device crashed and restarted by itself, a Crash report card appears under About the device. It says "The device restarted after a crash" and shows where it crashed. The details are for the developer.

Tap Share report to send the details to a bug report or a message. Tap Dismiss to remove the card once you have shared it. Dismissing works only while no Pokémon GO phone is connected. The card stays until you dismiss it, even after the device restarts again. The app needs the matching firmware version.

Diagnostics

Diagnostics reads detailed information from the device on demand. Nothing updates by itself. Tap Refresh on a dump to fetch the latest.

  • Runtime stats. Internal counters for the device's current session.
  • Task list. The device's internal task activity.
  • Client states. The state of each connected client, one per connection slot.

This output is raw and technical. Use it in a bug report.

Tap Share report to send all three dumps in one message, together with the app version, your phone model, your Android version and the device firmware version. Refresh the dumps first so the report is current. The report hides the secret codes of each connection, so it is safe to paste into a bug report.

Disconnect all clients

Drops every Bluetooth connection the device currently holds, including Pokémon GO's, not only the companion app's connection. Use it when something is stuck and you do not want to power-cycle the device.

Danger zone

These actions are irreversible and take effect immediately. Each opens a confirmation sheet that names what will happen. You type a confirmation word to enable the action. There is no undo.

Forget all pairings

Erases every pairing and setting on the device, then restarts it. The device keeps its clone identity, so it still looks like the same accessory. Pair your phone and Pokémon GO again afterwards.

Confirm with: FORGET

Reset session secrets

Erases the device's clone identity, address, and keys. The device restarts in setup mode and stops working until you import your secrets file again from the app. See Set up a device with no secrets.

Confirm with: RESET

Restart device

Restarts the device right away. Every Bluetooth connection drops immediately.

Confirm with: RESTART
