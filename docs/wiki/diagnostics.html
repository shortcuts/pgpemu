Status

The Status card at the top of the dashboard is a read-only snapshot of the device right now:

FieldMeaning
LED Whether the device's indicator light is currently on.
Advertising Whether the device is currently discoverable to new Bluetooth connections.
Connections How many devices are connected right now, out of the max set in Settings.
Log level The device's current logging detail: Debug, Info, or Verbose.

Diagnostics

Diagnostics pulls detailed, on-demand information straight from the device. None of it updates automatically — tap Refresh on any of the three dumps to fetch the latest.

  • Runtime stats — internal counters for the device's current session.
  • Task list — the device's internal task activity.
  • Client states — the state of each connected client, one per connection slot.

This is raw, technical output meant to be copied into a bug report rather than read at a glance. Tap and hold any dump to select and copy its text.

Disconnect all clients

Drops every Bluetooth connection the device currently holds, including Pokémon GO's, not just the companion app's own connection. Useful for a clean restart when something seems stuck, without power-cycling the device itself.

Danger zone

These two actions are irreversible and take effect on the device immediately. Each opens a confirmation sheet naming exactly what will happen, and asks you to type a confirmation word before the action becomes available — there's no undo after that.

ActionWhat happensConfirm with
Reset session secrets Erases the device's clone identity, address, and keys. It will need to be paired from scratch afterward, in both Pokémon GO and the companion app. RESET
Restart device Restarts the device right away. Every Bluetooth connection drops immediately. RESTART
