Status

The Status card at the top of the dashboard is a read-only snapshot of the device right now. While you are connected, it and the device profiles refresh on their own every few seconds, so changes made from another phone show up without any action from you:

FieldMeaning
LED Whether the device's indicator light is currently on.
Advertising Whether the device is currently discoverable to new Bluetooth connections.
Radio Whether the device is sending out its Bluetooth signal right now. It reads Idle when Advertising is off or when the max number of connections is already reached, and Active otherwise. Newer firmware only.
Connections How many devices are connected right now, out of the max set in Settings.
Log level The device's current logging detail: Debug, Info, or Verbose.

About the device

Below Status, the About device card shows details the app reads once when it connects: the firmware version, how many connection slots the device has, how long it has been running, why it last restarted (for example power on, a restart from the app, or a crash), and how much free memory it has. If the card says the device runs old firmware, update the device to see these details.

Crash report

If the device crashed and restarted by itself, a Crash report card appears under About the device. It says "The device restarted after a crash" and shows where it crashed. The details are for the developer.

Tap Share report to send the details to a bug report or a message. Tap Dismiss to remove the card once you have shared it. Dismissing works only while no Pokémon GO phone is connected. The card stays until you dismiss it, even after the device restarts again. The app needs the matching firmware version.

Diagnostics

Diagnostics pulls detailed, on-demand information straight from the device. None of it updates automatically — tap Refresh on any of the three dumps to fetch the latest.

  • Runtime stats — internal counters for the device's current session.
  • Task list — the device's internal task activity.
  • Client states — the state of each connected client, one per connection slot.

This is raw, technical output meant to be copied into a bug report rather than read at a glance. Tap and hold any dump to select and copy its text.

Disconnect all clients

Drops every Bluetooth connection the device currently holds, including Pokémon GO's, not just the companion app's own connection. Useful for a clean restart when something seems stuck, without power-cycling the device itself.

Update firmware

You can update the device from your phone, without a computer or a cable. Download the pgpemu.bin file from the latest release to your phone first.

  1. Disconnect Pokémon GO from the device.
  2. Hold the button on the device board for 3 seconds, then let go. The device now accepts an update for 2 minutes.
  3. In the app, tap Choose pgpemu.bin, pick the file, and type UPDATE to confirm.
  4. Keep the phone close and wait for the progress bar to reach 100%. It takes a few minutes.
  5. The device restarts. Connect again from the app.

If the new firmware does not start properly, the device goes back to the old one by itself. This safety net only works once the device has been updated over USB with this version. Your pairings are kept.

When a newer release exists, the app shows an Update available card. Dismissing it hides it until the next release.

Danger zone

These actions are irreversible and take effect on the device immediately. Each opens a confirmation sheet naming exactly what will happen, and asks you to type a confirmation word before the action becomes available — there's no undo after that.

ActionWhat happensConfirm with
Forget all pairings Erases every pairing and setting on the device, then restarts it. The device keeps its clone identity, so it still looks like the same accessory. Pair your phone and Pokémon GO again afterwards. FORGET
Reset session secrets Erases the device's clone identity, address, and keys. The device restarts in setup mode and stops working until you import your secrets file again from the app. See Set up a device with no secrets. RESET
Restart device Restarts the device right away. Every Bluetooth connection drops immediately. RESTART
