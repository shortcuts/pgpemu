Acknowledgements

PGPemu builds on earlier work reverse-engineering the Pokémon GO Plus protocol, and the companion app is built using a number of open-source projects. Thanks to everyone who works on them.

Prior work

yohane's pgpemu

The original Pokémon GO Plus emulator this project is based on.

spezifisch's fork

Further protocol work carried forward into this project.

paper183's fork

Further protocol work carried forward into this project.

pogoplusle

A compatible client PGPemu is tested against for auto reconnect and handshake behavior. The Game monitor in the companion app is based on its code, under the Apache 2.0 license.

Companion app & Bluetooth

Nordic Android BLE Library (Nordic Semiconductor)

Used for: Handles the Bluetooth Low Energy connection, pairing, and the command/response protocol used to talk to the device.
